    notd: a simple outliner

    A lightweight, long-lived alternative to Logseq: an outliner for notes, journals and tasks made of plain PHP, plain JavaScript and one SQLite file that you own. No build step, no cloud, works offline.

    Get started View on GitHub

    Download as zip

    Minimal

    An outline, a journal page for every day, and Markdown. Enter, Tab, Backspace and Ctrl+Z work the way an outliner should, and a page of thousands of notes opens in under a second.

    Organised

    Links and backlinks, tasks, properties, embedded notes, live queries over your notes, namespaces, attachments, favourites and password-locked pages.

    Extendable

    Everything the interface does is available over an HTTP API. Included extensions: kanban board, pomodoro timer, attachment dashboard, zen editor and more.

    Built to last

    PHP, SQLite and plain JavaScript. No build step, no package manager, no framework to keep up with. If PHP runs, notd runs.

    Yours, offline

    Notes are plain text in one SQLite file on your machine, and export to Markdown files in Logseq's layout at any time. Nothing is loaded from the internet; edits made offline are sent when the server is back.

    Free

    notd is open source under the GPL 3, free for personal and commercial use.
