    Interface & Shortcuts

    .

    Layout

    AreaContents
    Left sidebarCalendar, search, recent pages, Search or Create Page, extensions
    CentrePage title (with the gear icon for page properties) and the outline
    Right sidebarFavorites, backlinks, child pages
    Bottom rightSave status

    Both sidebars can be collapsed with the arrows at the top. On a phone the sidebars are hidden and a toolbar at the bottom opens them and adds notes.

    The note menu

    Right-click a bullet for actions on that note:

    • Copy transclusion link: the !{{...}} text that embeds this note elsewhere
    • Copy anchor link: a URL to this note
    • Upload: attach a file
    • Open in Zen / Excalidraw / Math notepad: open the note in one of those extensions
    • Delete: remove the note and its children

    Keyboard shortcuts

    Anywhere

    ShortcutAction
    Ctrl + KGo to the search field
    Ctrl + SpaceSearch or create a page
    Shift + SpaceSearch notes (outside a note)
    Ctrl + BShow backlinks
    Ctrl + Alt + Left / RightPrevious / next day (on a journal page)
    EscapeClose a window

    In a note

    ShortcutAction
    EnterNew note below
    Shift + EnterLine break
    Ctrl/Cmd + EnterNew child note
    Tab / Shift + TabIndent / outdent
    Up / DownPrevious / next note
    Ctrl/Cmd + Up / Down or Alt + Shift + Up / DownMove the note up / down among its siblings
    Backspace in an empty noteDelete the note
    /Insert a template
    [[Suggest pages to link
    :t :k :d :r + spaceInsert {tag::}, {keyword::}, today’s date, the current time

    Themes

    Set ACTIVE_THEME in config.local.php to one of default, darkly, flatly, purple or ubuntu. A theme is a single CSS file of custom properties in assets/css/themes/; copy one to make your own.
