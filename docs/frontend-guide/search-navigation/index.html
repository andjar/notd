    .

    Search

    ShortcutWhat it searches
    Ctrl + KMoves to the search field in the left sidebar: full-text search across all notes, with results as you type.
    Ctrl + SpaceSearch or create page: find a page by name, or create it if it does not exist.
    Shift + SpaceNote search window (when the cursor is not in a note).

    In the result lists, use the arrow keys to move, Enter to open and Escape to close.

    What you can type:

    project management      notes containing these words
priority::high          notes with this property
TODO review             task notes containing "review"

    Encrypted pages are not searchable: the server only stores their ciphertext.

    For anything search cannot express, write a query in a note.

    Getting around

    • Calendar (left sidebar): jump to any day’s journal page.
    • Recent pages (left sidebar): the pages you opened last.
    • Favorites, backlinks and child pages (right sidebar): see Backlinks & Favorites.
    • Page links: [[Page Name]] in any note.
    • Zoom into a note: click its bullet to show only that note and its children; the breadcrumbs above lead back out.
    • Link to a note: right-click its bullet and choose Copy anchor link to get a URL that opens the page and highlights the note.
