Outliner first

A journal page for every day, notes nested as deep as you like, links and backlinks. Enter, Tab and Backspace work the way an outliner should.

Small core, plugins for the rest

The core does notes, links, search, queries, files and export. Tasks, git history and everything else are plugins written against the same public API.

Built to last

PHP, SQLite and plain JavaScript, with no build step and no framework to keep up with. A documented protocol and its test suite let either side be replaced.
