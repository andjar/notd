Minimal

An outline, a journal page for every day, and Markdown. Every bullet can be nested, collapsed, dragged and linked.

Organised

Tasks, backlinks, transclusion, properties, namespaces, attachments, SQL queries over your notes, and per-page encryption.

Extendable

Everything the interface does is available over an HTTP API. Included extensions: kanban board, pomodoro timer, attachment dashboard, zen editor and more.

Built to last

PHP, SQLite and plain JavaScript. No build step, no package manager, no framework to keep up with. If PHP runs, notd runs.

Yours, offline

Notes are plain text in one SQLite file on your machine. Nothing is loaded from the internet, and edits made offline are sent when the server is back.

Free

notd is open source under the GPL 3, free for personal and commercial use.
